# OSMANX PROOF R6 — зашифрованные доказательства работы

Статус: **feature branch / PR #1**, без объединения в `main` и без deployment. Пять реализованных блоков R6:

1. **Evidence Vault:** загрузка PDF/PNG/JPEG/TXT (≤2 МиБ), анализ формата по содержимому, AES-256-GCM, SHA-256, карантин до подтверждения сканером, физическое хранение вне `public`.
2. **Контур независимой проверки:** административная очередь, HMAC-SHA256 attestation от внешнего сканера, запрет поддельных и повторных подтверждений, отзыв доступа при угрозах. **Реальный антивирус не встроен** и не может считаться успешно прошедшим проверку без подключения отдельного сканера.
3. **Передача заказчику:** прикрепление только проверенных файлов к конкретной версии этапа, контроль временной клиентской ссылки, защищённая загрузка, квитанция приёмки с проверкой хешей вложений.
4. **Интерфейсы исполнителя и заказчика:** загрузка и статус карантина в Node SPA и Next.js, выбор проверенных вложений при сдаче, клиентские ссылки на скачивание и квитанции, мобильный клиентский портал.
5. **Миграции и инженерная приёмка:** PostgreSQL 16 RLS с отдельными таблицами, API/аудит, защита от чтения чужих файлов и от XSS в имени, новые интеграционные тесты и GitHub Actions.

## Важные ограничения

- Продукт находится в тестовой стадии. Публичный production **не открыт**.
- Сканер должен быть отдельным доверенным процессом, выдающим независимую подписанную оценку. Ни тестовый HMAC, ни ручная классификация не являются антивирусным анализом.
- Ключ AES-256-GCM обязателен; если не установлен, загрузка отключена (HTTP 503).
- Отзыв запрещает скачивание, но **не стирает** содержимое: сохранение и сроки удаления требуют отдельной политики и юридической проверки.
- Ссылки на принятие работ подтверждают действие обладателя ссылки, не личность или квалифицированную ЭП.
- По-прежнему нет реальных выплат, реального Stripe Live и автоматического deploy на домен.
