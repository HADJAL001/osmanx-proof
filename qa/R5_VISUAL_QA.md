# R5 visual review

- Rendered sample client portal HTML generated by the *actual R5 HTTP server* in a temporary SQLite instance. The demo information is synthetic.
- In Chromium, HTML/CSS were inserted via `page.set_content`; HTTP navigation was blocked by the environment. Therefore this is a **static visual inspection**, not an interactive end-to-end browser test.
- Desktop viewport 1440×960 and mobile viewport 390×844. `document.documentElement.scrollWidth > innerWidth` was false in both.
- Screenshots distributed separately as `/mnt/data/OSMANX_PROOF_R5_CLIENT_DESKTOP.png` and `/mnt/data/OSMANX_PROOF_R5_CLIENT_MOBILE.png`.
- The sample HTML `qa/r5_client_visual.html` has CSS inlined, no real users, secrets or bearer links and is supplied for local comparison.
