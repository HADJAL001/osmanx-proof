# OSMANX PROOF R1 — release notes

Дата: 19 ноября 2026 года.

**40/40 автоматических тестов пройдены.** Функциональные блоки 1–5 интегрированы и проверены для локального запуска. Визуальный Chromium mock QA: 7 снимков, без ошибок JavaScript. Browser E2E через localhost заблокирован политикой браузера в текущей среде, поэтому полноценная browser→API проверка не заявляется.

**Объём:** авторизация/организации/роли; расчёты коммерческих предложений с экспортом в браузерный PDF; счета/подписки/тестовые платежи и возвраты; реферальные начисления только за оплаченные продажи; админ-контроль, споры и журнал целостности.

**Не production:** Node.js + SQLite (вместо планируемого Next.js, TypeScript и PostgreSQL), эквайринг/payouts не подключены, нет юридической оферты и нативных мобильных приложений.

**Безопасность:** нельзя включать sandbox в production. Не отдавайте в интернет текущий прототип и не считайте учётные статусы проведёнными банковскими переводами.

**Запуск:** `npm start` (Node >=22.13). Тест: `npm run check`.
