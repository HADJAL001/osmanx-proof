# QA R1 — фактически выполненные проверки

Дата сборки: 19.11.2026.

- `npm run check` — **40 пройдено из 40** (Node 22.16.0), ноль ошибок.
- В том числе core tests: 30, HTTP integration tests: 10.
- Проверенные действия: регистрация, сессии, logout, CSRF, tenant isolation, роли и приглашения, создание и редактирование предложений, арифметика, ограничения тарифа, создание и симуляция счетов, HMAC, event replay, скидка только один раз, списание вознаграждения при refund, 14-дневная задержка, заявки на выплаты, аудит и проводки.
- Проверки XSS-escaping печатной страницы, недоступности sandbox в production и смены языка.
- Офлайн-визуализация в Chromium с mock-данными: **7 снимков**, `qa/visual_results.json` — ошибок JS браузера нет.
- Полный браузерный E2E через сетевую навигацию НЕ выполнен: Chromium отвечает `net::ERR_BLOCKED_BY_ADMINISTRATOR` даже для localhost. Это ограничение среды, а не положительная проверка приложения. Node HTTP-тесты используют настоящие локальные HTTP-запросы.
- Физический Android/iOS телефон НЕ проверялся.

## Ограничения и честный статус

Прототип работоспособен локально. Нет оснований называть его production-ready без замены тестового платёжного шлюза, DB runtime, пользовательских условий и независимой проверки безопасности. Экспериментальный SQLite API не рекомендуется использовать как финальное критическое хранилище.
