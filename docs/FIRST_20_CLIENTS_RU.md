# Первые 20 целевых бизнесов: испытание ценности OSMANX PROOF

Это подготовка пилота, не утверждение, что 20 клиентов уже найдено. Партнёрам разрешено участвовать бесплатно; приглашения нужны для продаж настоящих услуг, не для возврата взноса.

## Чёткое предложение

**Growth Setup — цена на согласование 40 000 ₽.** Диагностика потребностей, настройка рабочего кабинета, шаблоны предложений, обучение и передача результата. **Enterprise Setup — цена на согласование 200 000 ₽.** Выявление рабочих процессов, внедрение в несколько команд, согласование этапов, обучение и отчёт о приёмке. Ни один пакет пока не является продаваемой услугой до юридического утверждения и подтверждения себестоимости.

Продукт показывает клиенту, что оплачено, что сделано, кто принял результат и какие изменения нужны. Это конкретное преимущество против схем, где ключевое обещание — заработок от новых участников.

## Полевой протокол

1. Собрать **20 квалифицированных** представителей кофеен, стоматологий, магазинов одежды и B2B-услуг с повторными заказами. Не считать сотрудника без права решения платёжеспособным заказчиком.
2. На первой встрече выяснить проблему и стоимость потери: несогласованные работы, запоздалые ответы, неотслеженные этапы, спорные возвраты. Не обещать гарантированный процент роста прибыли.
3. Показать TEST-кейс: предложение → принятие → план работ → доказательства → правки → финальная приёмка. Запросить разрешение на следующую встречу.
4. Предложить 5 добровольных бесплатных пилотов с фиксированным составом и сроком. Согласовать правила хранения данных и закрытия доступа.
5. Получить письменную обратную связь: стало ли проще контролировать работу, платить ли за этот результат без бонусов за приглашение друзей. Отдельно спросить причину отказа.
6. После юридического и технического GO / LIVE — тестировать платную продажу и рассчитывать фактические, а не предполагаемые расходы. Пока это только план.

## Минимальная аналитика

`examples/pilot-20.csv` — синтетические записи. В своём CSV замените только обезличенные ID, канал и стадии, ставьте `test_only=1` для TEST. Поля стоимости заполняются лишь при подлинных денежных операциях с доказанной оплатой; учёт по CSV сам по себе платёж не подтверждает. Запуск:

```sh
node scripts/pilot-metrics.mjs examples/pilot-20.csv
node scripts/pilot-economics.mjs
```

Каждую неделю отслеживать количество квалифицированных контактов, долю предложений, реальных сделок после легализации, завершение работ, сроки, возвраты, себестоимость и маржу. Для валидного вывода провести хотя бы 5 независимых пилотов; не интерпретировать 0 платящих клиентов как положительную экономику.

## Критерий перехода

Бета имеет смысл, если клиент, который никогда никого не пригласит, всё равно получает самостоятельно полезную услугу. Масштабировать программу только после подтверждённой повторяемости выполнения и маржинальности, а не благодаря обещанию будущей выплаты.
