# OSMANX PROOF — инженерное решение перед запуском

Дата: 20 ноября 2026 г. Режим: **NO-GO для публичной коммерции**, закрытое тестирование только после отдельной staging-приёмки.

## Фактически подтверждённый исходный код

На GitHub `HADJAL001/osmanx-proof` последняя найденная функциональная ветка — `feature/r7-partner-450` (`e5261211ac89b195982eff6093245b79be8bfad3`). Базовый `main` содержит стабильный R5. Независимо собранных R8–R13 исходников в GitHub нет; текущий пакет не заявляет, что импортировал или протестировал эти версии. Пакет прикладывается поверх R7 и **ничего не меняет в механизме денег**.

## Пять блоков проверки (реализованы в файлах)

1. `scripts/pilot-inventory.mjs` — контролирует наличие R7 исходников, команд проверки, Next.js lockfile, физическое наличие заявленного R13. Незавершённый выпуск не может называться R13.
2. `scripts/pilot-verify.mjs` — изолированно запускает `npm run check`, HTTP acceptance, нагрузочный smoke, зашифрованное восстановление. Пишет отчёты с SHA-256 и не включает реальные платежи. При отсутствии `web-next/package-lock.json` сборка Next не заменяется недетерминированным `npm install`.
3. `scripts/pilot-gate.mjs` — режимы `demo`, `beta`, `paid`. По умолчанию возвращает `NO_GO`. Для beta требуется HTTPS staging, browser E2E, доказательства изоляции tenant, защита данных, восстановление и воспроизводимая сборка. Режим paid требует значительно больше доказательств и **не разрешает реальные выплаты одним JSON-флагом**.
4. `scripts/pilot-economics.mjs` — расчёт комиссий на реальных B2B-услугах: максимум 10% от цены и 35% расчётной маржи до комиссии. Все сценарии явно помечены как гипотетические. Нет бонуса за вход или приглашение двух человек.
5. `scripts/pilot-metrics.mjs` — проверка анонимизированного CSV воронки; раздельно учёт TEST и реальных клиентов, не допускает подмены этапов, завышения комиссий и возвратов. Не печатает ID лидов и не подтверждает платежи самостоятельно.

Все модули используют только Node.js 22 и встроенные библиотеки. 35 автономных тестов находятся в `tests/pilot-launch.test.mjs`. GitHub Actions для отдельного PR: `.github/workflows/pilot-launch-readiness.yml`.

## Последовательность работы

**Шаг A — код и воспроизводимость.** Дождаться 3 основных зелёных CI (backend, PG16 RLS, Next build) на конкретном коммите. Исправить `web-next/package-lock.json` и перейти на `npm ci` для reproducible build, не подменяя его `npm install` на неизвестных версиях. Свести R8–R13 из подлинных архивов, сверить SHA-256, заново запустить весь регресс. Пока исходники не доступны, не заявлять, что единый R13 собран.

**Шаг B — закрытый тест без денег.** Изолированный staging-домен с TLS, тестовые организации, 10–20 приглашённых тестировщиков. Сценарий: регистрация → коммерческое предложение → ответ → выполнение → исправления → клиентская приёмка → возврат в TEST-сценарии. Проверить восстановление, доступ к чужим данным, телефон, планшет, desktop. Ни реальные карты, ни обещания выплаты в бете.

**Шаг C — демонстрация ценности.** Провести не менее 20 интервью с бизнесами, 5 бесплатных/TEST пилотов, документировать реальное время выполнения, понятность продукта и решение покупателя. Использовать `examples/pilot-20.csv`, заменить синтетические записи обезличенными и держать `test_only=1` до законных настоящих сделок.

**Шаг D — коммерция.** Только после согласования договоров, политики конфиденциальности, правил возврата, налогов, KYC, реальных платежей, антифрода, независимого security review и раздельной банковской сверки открыть продажи. Реальные партнёрские комиссии — лишь за принятую покупателем услугу и по марже, не за рекрутинг. Бюджет и стоимость привлечения подтвердить на первой партии заказов.

## Непреодолимые на текущем этапе ограничения

- Не представлены исходные байты R8–R13, поэтому нельзя их объединить автоматически.
- Коммерческий платёжный провайдер не подключён; выплаты = 0.
- Только внешние логи, фактический staging и независимое ревью могут подтвердить полноценную готовность.
- Отсутствует доказательство 20 реальных платящих клиентов; сценарии выручки являются оценками.
- Модель USD 91 000 за привлечение 450 человек не является частью OSMANX. 450 — маркетинговая цель по подтверждённым продажам, не обещание дохода.
