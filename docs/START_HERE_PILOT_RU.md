# OSMANX PROOF — пакет подготовки закрытого пилота

**Это дополнение к фактическому R7, а НЕ новый полноценный R13.** Не содержит исходный код всего сервиса, не включает ключи, базы или реальные платежи.

## Проверить комплект без установки зависимостей

```sh
node --version                 # Node 22.13+
npm test                       # 35 автономных тестов
npm run economics              # гипотетическая маржа 40k и 200k
npm run metrics                # только синтетическая воронка
npm run gate                   # ожидаемо NO_GO для публичной беты
```

## Подключить к реальному R7 (рекомендуемый путь)

1. В GitHub откройте новую ветку от `feature/r7-partner-450`.
2. Скопируйте `scripts/pilot-*.mjs`, `tests/pilot-launch.test.mjs`, `docs/*`, `examples/*`, `.github/workflows/pilot-launch-readiness.yml` в корень R7. **Не заменяйте исходный `package.json` из R7 на пакетный** — он только для независимого ZIP-набора.
3. Запустите `node scripts/pilot-inventory.mjs --repo .`.
4. Запустите `node scripts/pilot-verify.mjs --repo . --output .pilot-qa`; не публикуйте папку `.pilot-qa`, логи и личные данные в GitHub.
5. Проверьте ожидаемую блокировку публичного beta: `node scripts/pilot-gate.mjs --repo . --stage beta --evidence .pilot-qa/evidence.json`.
6. Дальнейший маршрут — `docs/LAUNCH_DECISION_RU.md`.

**Не устанавливать Next.js с непроверенным lockfile.** При отсутствии `web-next/package-lock.json` воспроизводимый Next build остаётся блокером. Гарантированный `NO_GO` для коммерции не ошибка: в TEST нельзя собирать деньги или делать реальные выплаты.

## О безопасности

Вывод отчётов не содержит приватные поля воронки; лабораторные файлы CSV используют обезличенные идентификаторы. Объекты `evidence.json` и `.log` — локальные документы, не цифровая подпись независимого аудитора. Чистые тесты кода не доказывают, что staging или юридические документы проверены.
