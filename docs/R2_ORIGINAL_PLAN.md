# R2: следующие пять крупных задач

Этот документ — план, **не реализованные функции**.

1. **PostgreSQL + TypeScript + Next.js.** Миграции с совместимостью тестов доменной экономики, SSR-роутинг, production auth/session, tenant RLS, outbox.
2. **Платежи и возвраты.** Законно выбранный провайдер эквайринга, нативная проверка webhook, сверка расчетов, отмена подписки, реконсиляция и компенсации.
3. **Партнёрство и антифрод 2.0.** Подтверждённые email, внешние проверки риска с согласиями, настраиваемая политика комиссий, payout provider после правового одобрения.
4. **Клиентская коммерческая воронка.** Клиент подтверждает предложение, запрос изменений, согласование этапов, управляемые документы, история работы и SLA по ответам.
5. **Production QA и выпуск.** E2E desktop/mobile, load, security, backup-restore, мониторинг, аналитика пользовательской ценности, staging и согласованная rollout-процедура.

За R2 нельзя отчитываться как за готовый релиз, пока реализации не прошли интеграционные тесты и проверку в целевой инфраструктуре.
