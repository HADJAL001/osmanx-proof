# OSMANX PROOF — готово к публикации в GitHub

Этот комплект — **полноценный локальный Git-репозиторий**, а не просто папка с исходниками. В ZIP включена скрытая папка `.git`, поэтому сохранена история R1–R5, теги и отдельная ветка с незавершённой работой R6.

**GitHub пока не изменён**: в текущем окружении нет функции создания нового репозитория и доступа к локальной сессии `gh` на вашем Windows.

## Самый короткий путь (Windows)

1. Распакуйте ZIP с сохранением всех файлов, включая `.git`.
2. Убедитесь, что установлены Git и GitHub CLI (`gh`), а вход выполнен как `HADJAL001` (`gh auth status`).
3. Запустите `PUBLISH_WINDOWS.cmd` либо выполните PowerShell-команду ниже из папки с исходниками:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\publish-github.ps1 -Owner HADJAL001
```

Это создаст приватный `HADJAL001/osmanx-proof` и отправит `main`, теги `r1`—`r5` и ветку `feature/r6-evidence-vault`. Для аккаунта `osmanosmanov6880-bot` замените `-Owner` на него и активируйте его в `gh`.

Перед публикацией скрипт проверяет git-историю на опасные типы файлов и характерные сигнатуры ключей. Проверка не гарантирует отсутствие любых секретов.

## Что где

- `main` — проверенный локально релиз R5, 218/218 тестов и 14/14 HTTP-сценариев.
- `r1`…`r5` — реконструированные по полным ZIP-снимкам предыдущие релизы.
- `feature/r6-evidence-vault` — незавершённый R6, не сливать в `main` до приёмки.
- `.github/workflows/ci.yml` — CI, требующий внешнего GitHub Actions для настоящей проверки Next.js и PostgreSQL.
- `docs/GITHUB_SETUP_RU.md` — более подробная инструкция.

Ни Next.js, ни PostgreSQL, ни внешние платежи на production пока не подтверждены. Репозиторий является исходным кодом, **не действующим публичным сервисом**.
