# OSMANX PROOF R7 — ЧТО СДЕЛАТЬ ДЛЯ ЗАПУСКА

**В этой поставке — действительная R7 и проверочные инструменты пилота, а не R13.** Реальные платежи и выплаты запрещены.

1. Проверка: `npm run check`, `npm run acceptance:r5`, `npm run drill:encrypted`.
2. Закрытая локальная версия: `npm run pilot:private`; зайдите на `http://127.0.0.1:3100`.
3. Для команды и VPS используйте **SSH-туннель**, а не открытый порт: см. `docs/PRIVATE_PILOT_RUNBOOK_RU.md`.
4. Next.js: закреплён `web-next/package-lock.json`; для отдельной Next-сборки используйте `cd web-next && npm ci && npm run typecheck && npm run build`. Backend и Next — разные запуски.
5. Стадия **публичной** беты / коммерческого запуска пока `NO_GO`: не разрешены публичная оплата, вывод партнёрских бонусов, открытая регистрация на домене.

Проект находится в GitHub `HADJAL001/osmanx-proof`, ветка `feature/pilot-launch-readiness`, Draft PR #3. `main` и production **не** изменены.

**Если у вас более поздние R8–R13 ZIP:** эти исходники отсутствуют в нынешней проверенной поставке. Потребуется отдельная интеграция после предоставления архивов; смешивать релизы без тестов нельзя.
